# 3D 方块炮击消除游戏

## 项目定位

本项目是一款将三种玩法融合的休闲益智游戏：

- **Cubeland**：提供立体方块模型、角色与建筑表现。
- **Smashfest**：提供炮击操作、碰撞反馈和物理破坏爽感。
- **Spireblast**：提供颜色消除、连锁反应和关卡目标规则。

玩家需要瞄准由小方块组成的 3D 模型发射炮弹。炮弹命中后会破坏方块，并按照颜色消除规则触发连锁；失去支撑的方块会下落或坍塌。游戏的核心体验是：**瞄准破坏的操作感 + 消除解谜的策略性 + 立体结构坍塌的爽感**。

## 核心循环

```text
观察模型结构
→ 瞄准颜色或支撑点
→ 发射炮弹
→ 方块受击并产生冲击反馈
→ 同色方块达到数量后消除
→ 上方结构下落或坍塌
→ 触发连锁消除
→ 完成关卡目标
```

## 核心设计原则

1. **玩家是在瞄准和破坏，而不是单纯点击三消。** 炮弹的角度、落点、反弹和打击顺序必须影响结果。
2. **3D 结构必须参与规则。** 底部支撑、内部核心和悬空结构都应该影响坍塌结果。
3. **消除结果必须有强反馈。** 每次命中、消除、连锁和坍塌都要让玩家清楚看到并感受到结果。
4. **策略和爽感保持平衡。** 玩家可以快速射击，但合理选择颜色和支撑点应获得更高收益。

## 基础玩法规则

### 炮击

- 玩家从固定炮台或发射器发射炮弹。
- 第一版支持瞄准方向和发射；后续可加入力度、反弹和特殊炮弹。
- 炮弹数量有限，关卡结束时剩余炮弹可转化为奖励。
- 普通炮弹优先作用于命中的方块，不直接对整个模型扣血。

### 方块状态

建议普通方块采用两阶段破坏：

1. 第一次命中：方块出现裂纹或受损状态。
2. 第二次命中：方块破碎并进入消除判定。

特殊炮弹可以改变这个流程，例如范围破坏、穿透或一次性消除同色方块。

### 颜色消除

- 同色且相邻的方块达到 **3 个或以上** 时消除。
- 消除完成后，上方方块下落。
- 没有与底部支撑连接的结构视为悬空，并自动坍塌。
- 一次下落造成新的同色连接时，继续触发连锁消除。
- 颜色消除应优先判定连接关系；物理表现随后播放，避免规则结果不稳定。

### 结构破坏

- 底部方块是基础支撑点。
- 内部核心被破坏后，外层结构可能失去支撑。
- 单侧支柱被清除时，模型可以向另一侧倾斜或坍塌。
- 头部、翅膀、手臂、核心等部位可以作为关卡目标。
- 结构坍塌应是消除的结果，而不是完全随机的物理事件。

## 颜色与特殊方块

第一版使用四种基础颜色，并保留后续扩展空间：

| 类型 | 作用 |
|---|---|
| 红色 | 普通方块，承担基础连接和破坏功能 |
| 黄色 | 高分或范围奖励方块 |
| 蓝色 | 可用于减速、冻结或改变下落节奏 |
| 紫色 | 可作为穿透、爆炸或连锁触发方块 |
| 灰色 | 锁定/装甲方块，需要额外命中或特殊条件 |

第一版不必同时实现所有特殊效果。优先完成普通方块、颜色连接、支撑判断和一次连锁。

## 操作与反馈规范

### 命中反馈

- 炮弹命中时出现闪光、碰撞音效和短暂受击动画。
- 方块受损时出现裂纹、颜色变化或轻微抖动。
- 方块破碎时产生碎片和小范围粒子效果。

### 连锁反馈

- 每次连续消除提高音效音阶或提示强度。
- 屏幕显示连击数量和得分增加。
- 连锁达到较高等级时加入短暂镜头震动或镜头拉近。

### 坍塌反馈

- 大规模坍塌可以触发短暂慢动作。
- 方块落地时产生尘土、弹跳和碰撞音效。
- 关键部位破坏时显示明确提示，例如 `CRITICAL`、`COMBO` 或部位名称。
- 镜头震动必须短促且有上限，不能影响瞄准和观察。

## 关卡目标

关卡目标可以组合使用：

- 拆除模型的头部、核心或指定部位。
- 清除指定颜色的方块。
- 在限定炮弹数量内完成目标。
- 触发指定次数的连锁坍塌。
- 让模型向指定方向倒塌。
- 击落宝箱、装饰物或其他奖励目标。
- 保留指定方块，避免误伤目标结构。

第一版建议只使用“清除指定部位”和“限定炮弹数量”两个目标，确保规则容易理解。

## 首版原型范围

首个可玩版本只验证核心手感，不扩展完整内容：

- 一个固定视角的 3D 方块塔。
- 5 层高度，每层约 5～7 个方块。
- 4 种颜色。
- 一个固定炮台和普通炮弹。
- 支持瞄准、发射、命中、方块受损和破碎。
- 支持 3 个同色方块消除。
- 支持底部支撑判断和上方方块下落。
- 支持至少一次连锁消除。
- 包含基础命中闪光、碎片、尘土、音效和轻微震动。
- 一个明确的胜利条件和失败条件。

首版暂不要求：完整角色模型、复杂物理模拟、多种炮弹、养成系统、商店、联网和大量关卡。

## 体验验收标准

原型达到以下标准后，才进入内容扩展阶段：

1. 玩家能在第一次尝试中理解“瞄准并发射炮弹”的操作。
2. 玩家能看懂哪些方块会因颜色连接而消除。
3. 玩家能观察到打掉支撑点会影响上层结构。
4. 命中、消除、连锁和坍塌之间的先后关系清晰。
5. 一次成功的连锁或大型坍塌能带来明显的爽感。
6. 结果具有可预测性：相同操作不会因为物理随机性产生完全不同的规则结果。
7. 玩家失败时能知道是炮弹用完、目标未完成，还是结构处理顺序错误。

## 后续扩展方向

在首版验证成功后，再逐步加入：

- Cubeland 风格的动物、角色和建筑模型。
- 反弹、穿透、爆炸、吸附等特殊炮弹。
- 不同材质和不同支撑强度的方块。
- 多种坍塌方向和机关结构。
- 关卡星级、金币和奖励系统。
- 更复杂的部位目标和保护目标。
- 更丰富的 Smashfest 风格镜头、音效和粒子反馈。

## 制作时的防偏离检查

每次新增功能都应回答以下问题：

- 它是否增强了“瞄准破坏 + 颜色消除 + 结构坍塌”的核心循环？
- 玩家能否清楚理解它造成的结果？
- 它是增加策略，还是只增加视觉噪音？
- 它是否让物理随机性覆盖了消除规则？
- 它是否仍然适合短时、轻量、连续尝试的休闲体验？

如果一个功能不能增强核心循环，或者让结果变得不可预测，应暂缓加入。
